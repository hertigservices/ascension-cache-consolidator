# Using the data (moved)

This guide now lives with the tools it describes:

**[docs/USING-THE-DATA.md in Ascension Preservation](https://github.com/hertigservices/Ascension_preservation/blob/main/tools/cache-consolidator/docs/USING-THE-DATA.md)**

There is one copy of it, and this is a signpost to that copy — not a second one.
Every command in the guide belongs to a tool in that repository, so the guide is
kept beside those tools, where the person changing a flag will see it. When this
page held its own copy, the two drifted apart in a single day. Please do not
restore a copy here: bring changes to the canonical guide instead.

What is on the other side: how to install these caches into a World of Warcraft
client, how to import them into a server's world database, how to check the
result in game, and what the dataset can and cannot tell you. The dataset those
instructions read is the [cachedata/](../cachedata/) folder in this repository.
