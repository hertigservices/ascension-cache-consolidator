# Data repository ownership

This repository owns published datasets and provenance. Source code belongs in
hertigservices/Ascension_preservation under tools/cache-consolidator. Do not copy
tool implementations back here. Preserve every valid captured variant and its
source/mode attribution. Supplemental catalogs remain separately attributed.

The cache publisher audits cachedata before committing it. Supplemental BisBeard
snapshots must pass the canonical import_bisbeard.py verify command; see each
snapshot's publication review. Do not publish raw inbox files, private intake
configuration, credentials, character backups or arbitrary database dumps.
